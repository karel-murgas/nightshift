05

the board — eight directories of markdown

No database. No daemon. A card is a file.

mineideas/private. no script reads it
mineinbox/a rough note, no schema
i approvetasks/ready — waiting for my nod
i answerneeds-decision/a question only I can settle
machinereview/gates green
i testtesting/merged, waiting on me
archivedone/kept as evidence
archivefailed/kept too

A card's state is which folder it sits in. That is what survives a 3 AM reboot.

06

nothing runs itself

Four things I do by hand.

1 · capture drop a note

Into inbox/, from the phone. No frontmatter — refining it is the system's job.

2 · scope run triage

One note at a time, when I ask. It writes a card — or parks a question rather than guess.

3 · approve read the card

I read its ## Approach. Nothing dispatches that I have not agreed with.

4 · dispatch start the runner

By hand, or on a schedule I set. Stops on a wall, a budget, or .ai/STOP.

07

step 3 — the approval point

One paragraph decides whether it runs.

id: heavy-guard-should-bleed
tier: worker   worker: code-thread   unattended: true
## Intent
## Approach is_drone did double duty — AI and crit-DoT flavour. Add an independent is_mechanical flag for the flavour, and leave is_drone to the AI.
## Steps  ·  ## Acceptance  ·  ## Open Questions → none

The principle, not the diff. A gate refuses a tasks/ card that has no such paragraph.

08

what the night does with an approved card

worktreeits own branch — the integration branch is untouched
dispatchone worker, one card, at the tier the card declares
gates + teststhe machine judges first — I never read failed work
reviewan agent that sees the diff, never the prompt
mergerebased, re-verified, then merged
digestwhat landed, what failed, what needs me

Every branch in the runner is a file check or an exit code. Zero LLM calls in the orchestrator — that is what makes 3 AM predictable.

2 · clusterthe shape of an error repeats, not its subject

3 · earn a gateor refuse one and say so — judgment stays human

You get the machinery for earning gates — not our gate suite. A new repo starts with the generic ones and an empty log.

13

before you get excited

What you don't get.

  • ✕A pre-earned gate suite. Week one is generic gates and an empty log.
  • ✕Non-Python support. The AST gates assume Python underneath.
  • ✕Local models. Costed against real telemetry, then parked. Nothing depends on them.
  • ✕A sandbox. The permission mode a code card needs is the whole machine.
14

try it

Two commands to stand it up.

pip install -e path/to/nightshift
nightshift init --integration <your-branch>

# then, whenever you want it
python -m nightshift.runner --dry-run
python -m nightshift.runner --card <id> --max-cards 1

permission_mode: bypassPermissions is what a code card needs — and it is the whole machine, not a sandbox. init will never set it for you.
